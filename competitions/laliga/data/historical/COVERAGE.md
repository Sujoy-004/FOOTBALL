# Historical LaLiga Backfill — Coverage Report

Repo: `competitions/laliga` — Seasons **2000/01 → 2025/26** (380 matches per season; a complete 20-team double round-robin, final scores + closing 1X2 odds where the archive supplies them).

## Dataset location

- Per-season: `competitions/laliga/data/historical/<season>/{matches.json, elo_ratings.json, PROVENANCE.json}`
  (git-tracked; the approved `data/seasons/` path is the gitignored runtime store — deviation recorded in each `PROVENANCE.json`).
- Merged evaluation replay: `competitions/laliga/data/historical/replay_2000_01_2025_26.json` (named for the window it contains; the name is owned by `historical_backfill/contract.py:REPLAY_NAME`).
- Evaluation: `competitions/laliga/data/historical/evaluation/eval_results.json` (regenerated by `historical_backfill/evaluate.py` in the same change as the corpus).

## Signal availability (honest)

- `market_odds`, `refined_elo`, `rolling_form`, `rest_days`: available in **all** 26 seasons.
- `market_odds` (closing line): **9114 / 9880** matches (92.25%). The 766 without are 2000/01 (0/380) and 2001/02 (0/380) — those archive seasons pre-date the Pinnacle/Bet365/Max/Avg columns entirely — plus 1 match in 2002/03 and 5 in 2003/04 where the single quoted book gave no line. `odds_known_at` is recorded as `event_date` (closing line knowable at kickoff — documented assumption).
- `squad_value`: **omitted** — no prebuilt/licensed historical source; never fabricated (approved decision).
- Bookmaker distribution across the 9114 odds-bearing matches: **Pinnacle 5123, Bet365 3991** (Bet365 is the pre-Pinnacle-era fallback; Max/Avg never selected because a preferred book is always present), all odds > 0.

## Limitations

1. **Closing-line-odds-at-kickoff**: football-data.co.uk publishes no intraday odds timestamps; `odds_known_at` is set to the match `event_date` (documented assumption). No odds are ever used to predict their own fixture.
2. **Early-season odds absence**: 2000/01 and 2001/02 have no usable closing line in the archive (and 2002/03, 2003/04 miss 1 and 5 rows); these gaps are reported, never filled. Any market-odds comparison is computed on the covered sub-population only.
3. **Elo snapshot mirror**: live api.clubelo.com unreachable here; uses the MIT-licensed ClubElo archive mirror. One snapshot per season, strictly before MD1 (e.g. 2000/01 first match 2000-09-09 vs snapshot 2000-09-01; 2025/26 first match 2025-08-15 vs snapshot 2025-08-01) — conservative/stale for later rounds by design (no post-match leakage).
4. **Timezone conversion**: football-data local CET/CEST times are converted to UTC via Europe/Madrid zoneinfo; ordering is true chronological order. Archive seasons before 2019/20 carry **no kickoff `Time`**, so those matches use local 00:00 (≈22:00–23:00 UTC the previous day); ordering remains correct and same-day matches are excluded from each other's prior windows.
5. **Single-season elo state**: each season's match set is evaluated against its own pre-season Elo snapshot; no inter-season elo carry-forward in the stored files.

## Provenance

Per season: `data/historical/<season>/PROVENANCE.json` (schema 1) records sources+URLs, licenses, fetch time, snapshot dates, per-season match/odds/elo counts, elo-missing teams, duplicate check, and SHA-256 of both generated files.
