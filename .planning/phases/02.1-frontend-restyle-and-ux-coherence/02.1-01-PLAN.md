  <action>
Download the Latin-subset woff2 for each required family/weight from Google Fonts and write
them to web/static/fonts/ with the exact filenames task 1 references. Run this PowerShell
recipe (pwsh) from the repo root — it queries the Google Fonts CSS2 API with a modern
browser User-Agent (required to receive woff2 rather than ttf), extracts the `/* latin */`
@font-face src URL, downloads it, and FAILS LOUDLY (throws) if the network is unavailable or
the API returns no latin woff2, so the phase can be re-run — it must NOT silently ship a
.gitkeep placeholder or any fallback. Files are served same-origin at runtime; Google hosts
are contacted ONLY here at acquisition time, never at runtime.

```powershell
$ErrorActionPreference = "Stop"
$ua = "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/125.0.0.0 Safari/537.36"
New-Item -ItemType Directory -Force -Path web/static/fonts | Out-Null
$targets = @(
  @{ file = "spacegrotesk-500.woff2"; family = "Space+Grotesk"; weight = 500 },
  @{ file = "spacegrotesk-700.woff2"; family = "Space+Grotesk"; weight = 700 },
  @{ file = "manrope-500.woff2";      family = "Manrope";       weight = 500 },
  @{ file = "manrope-700.woff2";      family = "Manrope";       weight = 700 },
  @{ file = "jetbrainsmono-500.woff2";family = "JetBrains+Mono";weight = 500 },
  @{ file = "jetbrainsmono-700.woff2";family = "JetBrains+Mono";weight = 700 }
)
foreach ($t in $targets) {
  $cssUrl = "https://fonts.googleapis.com/css2?family=$($t.family):wght@$($t.weight)&display=swap"
  $css = (Invoke-WebRequest -Uri $cssUrl -Headers @{ "User-Agent" = $ua } -UseBasicParsing).Content
  $m = [regex]::Match($css, "(?s)/\*\s*latin\s*\*/\s*@font-face\s*\{.*?src:\s*url\((?<u>[^)]+\.woff2)\)")
  if (-not $m.Success) { throw "ACQUISITION FAILED: no latin woff2 URL for $($t.family) $($t.weight) — network unavailable or Google Fonts API changed. Re-run when online." }
  $dest = "web/static/fonts/" + $t.file
  Invoke-WebRequest -Uri $m.Groups['u'].Value -OutFile $dest -UseBasicParsing
  if ((Get-Item $dest).Length -le 0) { throw "ACQUISITION FAILED: $dest is empty. Re-run when online." }
  Write-Output ("{0} -> {1} bytes" -f $t.file, (Get-Item $dest).Length)
}
Get-ChildItem web/static/fonts/*.woff2 | Select-Object Name, Length
```
