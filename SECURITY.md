# Security Policy

## Reporting Security Issues

We take the security and integrity of the FOOTBALL platform seriously.

If you believe you have discovered a security vulnerability in this project, please report it privately through GitHub Private Vulnerability Reporting:

1. Navigate to the repository's **Security** tab.
2. Select **Advisories** from the sidebar.
3. Click **Report a vulnerability** to open a confidential advisory draft.

Alternatively, you may contact the repository owner directly through GitHub.

Please do not disclose potential security vulnerabilities in public issues, discussions, or pull requests until they have been addressed.

## Scope & Verification

- This project processes external sports data and produces deterministic and Monte Carlo simulation outputs.
- API keys, credentials, and environment secrets must never appear in repository source code, tests, or build logs.
